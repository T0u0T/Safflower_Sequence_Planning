# DS-CA-ACO-2OPT

Simulation code for safflower multi-target picking sequence optimization.

## Requirements

Python 3.13

Install the required Python packages:

pip install -r requirements.txt

## Usage

Run the simulation experiments:

python DS_CA_ACO_2OPT.py 

## Description

The code includes the proposed DS-CA-ACO-2OPT algorithm, comparative algorithms, ablation tests, statistical analysis, and visualization of simulation results.

Field vision-based localization and robot motion control are not included in this repository.
